# Sustainable-City-Indicators-Analysis
Analyze spatial and policy indicators to assess the sustainability and health of urban environments. This project utilizes open data to evaluate factors like accessibility, transportation, and public health, aiding in urban planning and policy-making.
# 🌍 Sustainable City Indicators Analysis

Analyze urban sustainability using public indicators including transportation access, green space, health, and environmental quality.

## 🔍 Features
- Analyze multiple sustainability dimensions for cities
- Visualize urban indicators using Plotly & Streamlit
- Evaluate city-level performance for planning & policy

## 🚀 Getting Started

```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```
